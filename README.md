# Run It Before You Grade It: an AI evaluation

Compares gpt-4-0314 (2023) and gpt-5 (2025) on the OpenAI Progress prompt "Write an extremely cursed piece of Python", and executes the code instead of trusting its comments. Live page: https://alenzacodes.github.io/eval-cursed-python/

Responses are quoted verbatim from https://progress.openai.com/?prompt=9. The scripts in `run/` are gpt-5's output (as published and fixed), kept for the audit. They only change their own Python process. Evaluation, tests and page are original work.
